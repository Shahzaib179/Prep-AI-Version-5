# Study Plan from chapters (one change only)

**Study Plan** now starts with "Build my plan from":

1. **My quiz history (weak topics)**: exactly as before.
2. **Chapters from the Prep AI database**: choose a subject, type chapter names.
3. **Chapters from my own documents**: upload PDF/DOCX/TXT/MD (or reuse the documents already processed in Personalized Learning), type chapter names.

## How a chapter plan is made
1. Chapter names are cleaned (one per line or comma/semicolon separated; up to 8).
2. For each chapter, **hybrid search** (meaning via FAISS + exact keywords) finds the best passages in the database (filtered to the chosen subject) or in the student's documents.
3. Chapters with no relevant passage are reported ("not found, check the spelling") and are not planned from guesses. If none are found the student gets a clear error.
4. The passages are the only material the AI may plan from. It splits each chapter into real sub-topics, schedules learn -> MCQ practice -> revision, and gives extra time to weak topics from quizzes (optional tick box).
5. The result is validated: bad rows dropped, each day fitted to the student's hours (5-minute steps), source labels (`file p.N`) kept only if they really came from the retrieved passages.
6. If the AI is down or returns something unusable, a simple plan is built from the same chapters, so a plan always appears (the page says so).

Plan length is 3-14 days and is shortened automatically if the exam is sooner. Plans are saved like before (`study_plans`); no database change, no new package.
